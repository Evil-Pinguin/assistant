# 💠 AURA · Аврора — Personal AI Desktop Assistant

**Your computer. Your rules. Your assistant.**

Голосовой ИИ-ассистент для компьютера: не просто отвечает на вопросы, а **действует** —
запускает приложения, управляет системой, ищет файлы, видит экран, помнит ваши
привычки и выполняет ваши режимы и команды. С лицом, настроением и характером.

## 🚀 Быстрый старт

```bash
pip install -r requirements.txt
python main.py
```

Windows: то же самое или просто `run.bat`.
Linux: `sudo apt install python3-tk portaudio19-dev espeak-ng` перед pip.
macOS: `brew install portaudio python-tk`.

Проверка системы и логики: `python selftest.py`.

## 🗣 Как пользоваться

1. Включите **🎙 Микрофон** в шапке.
2. Скажите **«Аврора»** — лицо оживёт, появится waveform.
3. Команда: *«открой VS Code»*, *«включи рабочий режим»*, *«что у меня на экране?»*…
4. Или зажмите **Ctrl+Space** (глобально, из любого приложения) и говорите.
5. Можно печатать в строку внизу — всё то же самое.

## 🧩 Свои команды и режимы

Вкладки **«Команды»** и **«Режимы»**: название → фразы активации → действия.

Доступные типы действий (кнопками, без кода):

`Запустить приложение` · `Открыть сайт` · `Закрыть приложение` · `Напечатать текст` ·
`Нажать клавиши` · `Клик мышью` · `Прокрутка` · `Команда системы` · `Запустить Python` ·
`Громкость` · `Яркость экрана` · `Создать папку` · `Записать файл` · `ZIP папки` ·
`Переименовать` · `Переместить` · `Удалить (в корзину AURA)` · `Сказать фразу` ·
`Пауза` · `Поручение ИИ`

Teach Mode: **⏺ Учить** → делаете действия руками → **⏹ Стоп** → название → готовая команда.

## 🛡 Разрешения (вкладка «Разрешения»)

Три уровня: **SAFE** (ничего опасного), **NORMAL** (обычная автоматизация,
опасное — через «да/нет»), **GOD MODE** (полный контроль, по умолчанию выключен).
Каждую категорию (shell, удаление файлов, покупки, действия ИИ…) можно переключить
individualно: 🟢 разрешить / 🟡 спрашивать / 🔴 запрещено.

Удаление файлов — безопасное: в корзину `~/.aura_trash` с возможностью отмены.

## 🤖 Подключение ИИ

Настройки → 🤖 Нейросеть:

| Провайдер | Base URL | Ключ |
|---|---|---|
| OpenAI | `https://api.openai.com/v1` | нужен |
| OpenRouter | `https://openrouter.ai/api/v1` | нужен |
| DeepSeek | `https://api.deepseek.com/v1` | нужен |
| Groq | `https://api.groq.com/openai/v1` | нужен |
| **Ollama** (локально) | `http://localhost:11434/v1` | не нужен |
| **LM Studio** (локально) | `http://localhost:1234/v1` | не нужен |

Для 👁 Vision нужна модель с поддержкой картинок (например, `gpt-4o-mini`,
`gpt-4o`, `qwen2.5-vl` в Ollama — укажите её в «Vision-модель»).

Архитектура безопасности: **ИИ — мозг, а не исполнитель**. Он возвращает блок
действий, а выполняет его Tool Router с проверкой разрешений.

## 🧬 Характер

Настройки → «Характер речи»: `professional` («Команда выполнена.»), `friendly`
(«Готово! Всё запустила.»), `jarvis` («Разумеется.»), `anime` («Есть~ Выполняю!»).

Настроение живёт своей жизнью: энергия тратится на команды и восстанавливается
со временем, после простоя AURA **засыпает** (портрет с «zzz»), на фрустрацию
в вашей речи реагирует сочувствием.

## 🖥 Command Center — коротко

Слева — лицо и статус. Справа — 5 вкладок:

| Вкладка | Зачем |
|---|---|
| 💬 **Диалог** | переписка + панель «Активность» с кнопкой «⏪ Отменить последнее» |
| ⚡ **Команды** | ваши команды: фразы → действия (конструктор без кода) |
| 🎮 **Режимы** | Работа / Игры / Стрим / Ночь / Разработка + свои сценарии |
| 🛡 **Разрешения** | уровень доступа SAFE/NORMAL/GOD и правила по категориям |
| ⚙ **Настройки** | персона, голос, микрофон, ИИ, память. Редкое — в свёрнутом «Продвинутые» |

### 🙂 Лицо-аватар

`aura/face_images/` — 7 пиксель-арт портретов (neutral, listening, thinking,
speaking, success, error, sleep). Хотите другого персонажа — просто замените эти JPG
на свои картинки с теми же именами: код подхватит их автоматически
(если файлов нет — включится резервное рисованное лицо-HUD).

## 🔌 Плагины

Создайте `plugins/my_plugin.py`:

```python
def register(api):
    def h_battery(t, m, ctx):
        return "С горе пополам заряжено."
    api.add_skill("battery", [r"сколько заряда"], h_battery)
    # или новый тип действия:
    # api.add_action("brew_coffee", fn)
```

## ❓ FAQ

**Микрофон не работает** — `pip install PyAudio`; Linux: `sudo apt install portaudio19-dev`.

**Русский голос на Windows** — Параметры → Время и язык → Речь → русский голосовой
пакет; затем выберите голос в Настройках.

**Нет интернета** — поставьте `pip install vosk`, скачайте модель с
<https://alphacephei.com/vosk/models> и укажите путь в Настройках.

**Что безопаснее для начала** — уровень SAFE: AURA будет всё спрашивать и ничего
не удалять.
