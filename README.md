# 🤖 J.A.R.V.I.S. — голосовой ассистент на Python

Голосовой помощник в стиле Джарвиса из «Железного человека»: слушает микрофон,
выполняет команды на компьютере, у него есть **окно-пункт управления**,
**анимированное лицо**, реагирующее на действия, **свои команды** и
**подключение нейросети** (ИИ).

![Python 3.8+](https://img.shields.io/badge/Python-3.8%2B-blue) ![Windows](https://img.shields.io/badge/Windows-✓-success) ![Linux](https://img.shields.io/badge/Linux-✓-success) ![macOS](https://img.shields.io/badge/macOS-частично-yellow)

## ✨ Возможности

| | |
|---|---|
| 🎤 **Голос** | кодовое слово «Джарвис», затем команда. Работает и без кодового слова |
| 👂 **Слух** | Google Speech (онлайн) или **Vosk** (офлайн, без интернета) |
| 🗣 **Речь** | озвучка ответов через pyttsx3 (SAPI5 на Windows, espeak на Linux) |
| 🖥 **Управление ПК** | запуск программ, сайты, поиск, громкость, скриншоты, блокировка, выключение |
| 🧩 **Свои команды** | добавляются прямо в окне программы или в `data/custom_commands.json` |
| 🪟 **Пункт управления** | журнал, редактор команд, все настройки — в одном окне |
| 🙂 **Лицо** | анимированный HUD-«реактор»: покой, слушаю, думаю, говорю, тревога |
| 🤖 **ИИ** | любой OpenAI-совместимый API: OpenAI, OpenRouter, DeepSeek, Groq, **Ollama**, LM Studio. ИИ может и отвечать, и выполнять действия на ПК (по желанию) |

## 🚀 Быстрый старт

### Windows (рекомендуется Python 3.8–3.12)
```bat
pip install -r requirements.txt
python main.py
```
или просто двойной клик по `run.bat`.

### Linux
```bash
sudo apt install python3-tk espeak-ng portaudio19-dev
pip install -r requirements.txt
python3 main.py
```

### Проверка системы
```bash
python selftest.py
```
Покажет, чего не хватает, и проверит логику без микрофона и окна.

### macOS
```bash
brew install portaudio python-tk
pip install -r requirements.txt
python3 main.py
```

> ⚠️ На Windows `pip install PyAudio` обычно ставится с колёс. Если ошибка —
> `pip install pipwin && pipwin install pyaudio`.

## 🗣 Как пользоваться

1. Включите тумблер **«Слушать микрофон»** в шапке окна.
2. Скажите: **«Джарвис»** — лицо оживёт и станет слушать.
3. Скажите команду: *«который час»*, *«открой ютуб»*, *«сделай скриншот»*…
4. Или нажмите **«🎤 Слушать»** и говорите сразу команду, без кодового слова.
5. Можно печатать команды в строку внизу — работает так же, как голос.

### Что он уже умеет (встроенные команды)

- 💬 **«привет»**, **«кто ты»**, **«что ты умеешь»**
- ⏰ **«который час»**, **«какое сегодня число»**
- 🌦 **«какая погода»** / **«погода в Санкт-Петербурге»** (город по умолчанию — в настройках)
- 🌐 **«найди кулинарные рецепты»**, **«открой ютуб/вконтакте/гитхаб»**, **«открой сайт example.com»**
- ▶ **«включи на ютубе смешных котов»**, **«включи музыку»**
- 💻 **«открой блокнот/калькулятор/пейнт/проводник/диспетчер задач/терминал»**, **«запусти steam»**
- 📸 **«сделай скриншот»** (сохранит в папку и откроет её)
- 🔊 **«сделай громче/тише»**, **«выключи звук»**, **«громкость на 30»**
- ⏯ **«поставь на паузу»**, **«следующий трек»**
- ⌨ **«напечатай Привет, мир!»** (вставит текст в активное окно)
- 🪟 **«сверни все окна»**, **«заблокируй компьютер»**
- 🔋 **«сколько заряда»**
- ⏻ **«выключи компьютер»** / **«перезагрузи компьютер»** — с подтверждением «да/нет»
- 😴 **«спи»** — уходит в режим ожидания, **«проснись»** или кодовое слово — будит
- 🎲 **«подбрось монетку»**, **«брось кубик»**, **«расскажи анекдот»**
- 🧠 **«очисти историю»** — ИИ забывает контекст диалога

## 🧩 Свои команды

Вкладка **«Команды»** → **«＋ Новая»**:

- **Название** — любое имя, например «Режим игры».
- **Фразы** — по одной в строке, что говорить: `врубай игру`, `режим геймера`.
- **Действия** — по одному в строке в формате `тип | значение`:

| Тип | Пример | Что делает |
|---|---|---|
| `open_url` | `open_url \| https://twitch.tv` | открыть сайт |
| `open_app` | `open_app \| steam` | открыть программу/файл/папку |
| `shell` | `shell \| ipconfig` | выполнить команду системы |
| `press` | `press \| ctrl+shift+esc` | нажать горячие клавиши |
| `type_text` | `type_text \| Привет!` | вставить текст в активное окно |
| `volume` | `volume \| mute` | громкость: up / down / mute / 0–100 |
| `say` | `say \| Готово, сэр!` | озвучить фразу |
| `wait` | `wait \| 2` | пауза в секундах |

- **Ответ ассистента** — что озвучить после выполнения (необязательно).

Пример из коробки — файл `data/custom_commands.json`, можно править и руками.

## 🤖 Подключение ИИ

Вкладка **«Настройки» → 🤖 Нейросеть**. Подойдёт любой OpenAI-совместимый API:

| Провайдер | Base URL | Ключ | Модель |
|---|---|---|---|
| **OpenAI** | `https://api.openai.com/v1` | нужен | `gpt-4o-mini` |
| **OpenRouter** | `https://openrouter.ai/api/v1` | нужен | `deepseek/deepseek-chat` |
| **DeepSeek** | `https://api.deepseek.com/v1` | нужен | `deepseek-chat` |
| **Groq** | `https://api.groq.com/openai/v1` | нужен | `llama-3.1-8b-instant` |
| **Ollama** (локально) | `http://localhost:11434/v1` | не нужен | `llama3.1`, `qwen2.5` |
| **LM Studio** (локально) | `http://localhost:1234/v1` | не нужен | что загружено |

1. Поставьте галочку **«Отвечать через ИИ, если команда не распознана»**.
2. Впишите Base URL, ключ (если нужен) и модель → **Сохранить** → **Проверить связь с ИИ**.
3. Теперь всё, что не является командой, уходит нейросети: *«объясни квантовую запутанность»*.

### ИИ, который управляет компьютером
Включите **«Разрешить ИИ выполнять действия на ПК»** — тогда в ответах ИИ может
приходить блок действий, и Джарвис выполнит его: *«Джарвис, открой ютуб с музыкой
для работы»* → откроет и скажет. По умолчанию выключено из соображений
безопасности. Токены хранятся только в `data/settings.json` на вашем ПК.

## 🙂 Лицо

Лицо — это анимированный HUD-«реактор», он меняется по состояниям:

| Состояние | Когда | Что видно |
|---|---|---|
| 😌 Покой | ожидание | мягкое синее свечение, «дышит» |
| 👂 Слушаю | ждёт кодовое слово/команду | яркие глаза, волны-сонар |
| 🤔 Думаю | обрабатывает команду/запрос к ИИ | прищур, вращающиеся дуги и спутники |
| 🗣 Говорю | озвучивает ответ | рот-эквалайзер |
| ❗ Тревога | ошибка | красный пульс |

1. `pip install vosk`

## ❓ FAQ

**Микрофон не слышит / ошибка PyAudio** — на Windows: `pip install PyAudio`;
на Linux: `sudo apt install portaudio19-dev` и переустановить PyAudio. Проверить
уровень микрофона в системе.

**Говорит английским голосом** — установите русский голосовой пакет
(Windows: Параметры → Время и язык → Речь → добавить русский) и выберите голос
в Настройках. На Linux: `sudo apt install espeak-ng` + русские голоса
(`sudo apt install mbrola-ru1` — по желанию).

**«Команда не распознана»** — проверьте кодовое слово, интернет (для Google-движка),
или включите ИИ / добавьте свою команду.

**Хочу другой адрес будильника/софта** — не нужно: добавьте свою команду во вкладке
«Команды» (например, `shell | start "" "C:/games/game.exe"`).
