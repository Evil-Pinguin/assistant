## 1. Что это такое

**AURA (Аврора)** — персональный голосовой ИИ-ассистент рабочего стола на Python:
не чат-бот, а **агент, который действует** — запускает приложения, управляет
системой и файлами, видит экран через Vision AI, помнит предпочтения
пользователя, выполняет многошаговые сценарии и имеет живой анимированный
аватар с эмоциями, настроением и характером.

Ключевая идея: **лицо = состояние системы**. Аватар меняет эмоцию, цвет и
эффекты синхронно с внутренним состоянием ассистента.

```
ПОЛЬЗОВАТЕЛЬ
   │ голос (микрофон / Ctrl+Space / Ctrl+1…4) или текст в GUI
   ▼
SpeechRecognition (Google / Vosk) ──► транскрипт + уверенность
   ▼
BRAIN: подтверждения → встроенные навыки → режимы → свои команды → «открой …» → ИИ
   ▼
TOOL ROUTER: разрешения (SAFE/NORMAL/GOD) → действие → верификация
   ▼
КОМПЬЮТЕР (приложения, система, файлы, клавиши, браузер)
   ▼
ОТВЕТ: TTS-голос + лицо-эмоция + консоль-поток + RECENT-лента + Центр активности (undo)
```

(`log`, `state`, `heard`, `say_start/end`, `activity`, `mood`, `vu`), GUI
опрашивает очередь QTimer'ом — интерфейс никогда не зависает.

## 4. Машина состояний (aura/state.py)

Единый источник правды. UI, аватар, waveform, статус читают отсюда.
**LISTENING показывается только когда микрофон реально слушает.**

```
IDLE → WAKE → LISTENING → PROCESSING → EXECUTING → VERIFYING → SPEAKING
                                                        ↘ SUCCESS / ERROR → IDLE
+ ALERT (ошибка распознавания/внимание) · SLEEP (бездействие) · OFF (микрофон выкл)
```

| Состояние | Статус на экране | Эмоция аватара |
|---|---|---|
| idle | READY | спокойный взгляд |
| wake | I'M LISTENING | внимание |
| listening | LISTENING | внимательный взгляд, **рот закрыт** |
| processing | PROCESSING | прищур, взгляд в сторону |
| executing | EXECUTING | сосредоточенность, циановая подсветка костюма |
| verifying | VERIFYING | проверка |
| speaking | SPEAKING | говорит |
| success | COMPLETE ✓ | лёгкая улыбка (держится 2.2 сек) |
| error | ERROR | обеспокоенность + глитч (2.5 сек) |
| alert | ATTENTION | расширенные глаза, красные индикаторы |
| sleep | SLEEPING | закрытые глаза, «z-z-z» |

## 5. Лицо-аватар (aura/face_avatar.py + face_images/)

**Оригинальный персонаж AURA** (вдохновлён атмосферой SIGNALIS и ретро-CRT,
не копия существующего): молодая женщина-андроид — бледная фарфоровая кожа,
длинные платиново-белые волосы с неровными прядями, глубокие малиновые
искусственные глаза с внутренним свечением, тонкие синтетические швы на щеках,
ретрофутуристичный графитовый костюм с бело-серыми броневыми секциями,
циановыми светящимися проводками и красными предупреждающими метками.

- 9 JPG-портретов: `neutral, listening, thinking, executing, speaking,
  success, error, sleep, alert` (~1.3 МБ всего)
- Пиксельная сетка выровнена программно (даунскейл 224px → апскейл без
  сглаживания) — пиксели чёткие и одинаковые во всех кадрах
- **Эффекты:** плавный кроссфейд между эмоциями (без «двоения»), статичный
  кадр (без зумов и покачиваний), редкий глитч полосами при ошибке (раз в ~4
  сек), CRT-сканлайны, виньетка, цветная вуаль состояния, waveform внизу при
  слушании/говорении, «z-z-z» во сне
- Настроение (mood engine) подмешивает оттенок свечения в покое
- Кастомизация: заменить JPG в `aura/face_images/` своими с теми же именами;
  при отсутствии файлов автоматически включается рисованный HUD-вариант
  (`face_qt.py`: глаза-состояния, рот-эквалайзер, дуги, сонар-волны)

## 6. Голос и слух

### ear.py — слух
- **Движки:** `google` (онлайн, язык настраивается: ru-RU/en-US/…) или `vosk`
  (офлайн, путь к модели в настройках)
- **Уверенность STT**: приходит с каждым распознанным текстом, показывается
  на экране (`🎙 «открой код» · 93%`); ниже порога `stt_min_confidence`
  (настраивается, по умолч. 50%) — AURA честно пишет «не уверена, что
  расслышала» и просит повторить, не выполняя гадание
- **VU-метр**: уровни захваченной фразы (16 чанков через audioop.rms)
  отправляются в GUI
- **Диалоговый режим**: после команды/ответа AURA открывается окно
  `dialog_followup_sec` (по умолч. 25 сек), в течение которого кодовое слово
  не нужно: «Аврора» → «открой код» → «теперь терминал»
- **Режимы**: с кодовым словом («аврора») · push-to-talk кнопкой · Ctrl+Space
  глобально · прямой (без кодового слова)
- Выбор микрофона из списка устройств (`mic_device_index`), тест микрофона
  из настроек (2-сек запись с распознаванием)
- Калибровка под шум при старте; graceful-обработка отсутствия устройства

### voice.py — голос
- pyttsx3 в отдельном потоке с очередью; настройки: вкл/выкл, скорость,
  громкость, выбор системного голоса, тест из GUI
- При ошибке TTS — отключается с объяснением в журнале, приложение работает

## 7. Мозг (aura/brain.py) — pipeline команды

```
текст → подтверждение? → настроение (фрустрация?) →
  [1] встроенные навыки (35 шт., фаза 1)
  [2] режимы (профили)
  [3] свои команды (нечёткий поиск)
  [4] «открой/запусти …» (resolver, фаза 2)
  [5] ИИ (если включён) → ответ + блок действий
  [6] «не распознано» + подсказка
→ TOOL ROUTER (разрешения) → верификация → ответ TTS + лицо
```

- **Подтверждения**: опасное действие ставит pending-вопрос; «да/нет» в
  течение 60 сек; работает и голосом, и текстом
- **Персона**: 4 характера — `friendly` («Готово!»), `professional`
  («Команда выполнена.»), `jarvis` («Разумеется.»), `anime` («Есть~
  Выполняю!»). Acks подмешиваются к ответам о действиях
- **Эмоциональная реакция**: фрустрация в речи пользователя («сломалось»,
  «тормозит», «бесит») → эмпатия + смена настроения
- **Память диалога**: история для ИИ (deque, лимит настраивается),
  «очисти историю» сбрасывает

### Умный ответ ИИ (aura/ai.py)
Любой OpenAI-совместимый API. Системный промпт включает: личность AURA,
выбранный характер, память пользователя (prefs + факты), текущее настроение.
При `ai_allow_actions` ИИ в конце ответа может вернуть блок:

````
```aura
{"say": "Открываю", "actions": [{"type": "open_app", "target": "code"}]}
```
````

Блок парсится, действия проходят через разрешения. **ИИ — мозг, а не
исполнитель**: у него нет прямого доступа к ОС.

### Vision (aura/vision.py)
«Что у меня на экране» → ImageGrab → JPEG 1280px → base64 → Vision-модель.
«Нажми на кнопку Продолжить» → Vision ищет координаты элемента → действие
`click` (force_actions). Vision-модель настраивается отдельно.

## 8. Actions — Tool Router (aura/skills/actions.py)

20+ типов действий. Каждое: проверка разрешения → выполнение → запись в Центр
активности (с функцией undo, где возможно).

| Категории разрешений (14) | Действия |
|---|---|
| app_launch / app_close | `open_app` (с верификацией процесса), `close_app` (мягкое terminate + undo-перезапуск) |
| browser_open | `open_url` |
| shell / python | `shell` (timeout 30с, скрытая консоль), `run_python` (изолированный процесс) |
| files_read / files_modify / files_delete | `open_file`, `create_folder`, `write_file`, `zip_folder`, `rename_path`, `move_path`, `delete_path` (**корзина ~/.aura_trash** + undo) |
| system_volume / system_brightness | `volume` (up/down/mute/0-100), `brightness` (WMI/brightnessctl) |
| power | `power` (shutdown/reboot) |
| ai_actions | действия, предложенные ИИ |

Автоматизация (всегда разрешены): `press` (win+d, ctrl+s…), `type_text`
(через буфер), `click`, `mouse_move`, `scroll`, `say`, `wait`.
Плагины добавляют свои типы: `register_action(type, fn)`.

**execute_actions возвращает честный итог (ok, failed)** — AURA не скажет
«выполнено», пока не выполнено. `open_app` **верифицирует запуск**: после
старта до 5 сек ищет процесс через psutil → «Запуск: code ✓» или «(не
удалось подтвердить)».

### Application Resolver (aura/resolver.py)
`resolve("браузер")` ищет по приоритету:
1. реестр пользователя `app_registry` (имя → путь/exe)
2. встроенные алиасы (браузер→chrome, код→code, юнити хаб→unityhub…)
3. PATH (shutil.which)
4. ярлыки Start Menu / рабочего стола (Windows .lnk)
5. уже запущенные процессы (psutil) → «уже запущено»

## 9. Разрешения (aura/permissions.py)

Три уровня: **SAFE** (ничего опасного, shell/python/удаление запрещены) ·
**NORMAL** (автоматизация да, опасное — через подтверждение) ·
**GOD MODE** (всё без вопросов, по умолчанию выключен).

Каждую из 14 категорий можно переопределить индивидуально:
🟢 allow / 🟡 confirm / 🔴 deny. Действия с `confirm` перед выполнением
спрашивают «да/нет» голосом. `strip_denied` вычищает запрещённые шаги из
workflow заранее и объясняет, что отклонено.

## 10. Память, режимы, настроение

### Память (aura/memory.py) — data/memory.json
- **Предпочтения** (ключ→значение): «запомни: папка проектов D:/Projects»
  распознаётся структурно → потом «открой мой последний проект» работает
- **Факты**: свободные записи «запомни: …» (до 100), «что ты помнишь» — сводка,
  «забудь всё» — с подтверждением. Память подмешивается в промпт ИИ.
  Редактируется в настройках GUI.

### Режимы (aura/profiles.py) — data/profiles.json
Встроенные: 💻 Работа (code+почта+громкость 30) · 🎮 Игры (steam+discord+60) ·
🎥 Стрим (obs+discord) · 🌙 Ночь (яркость 40+громкость 20) · 🚀 Разработка
(code+терминал+github). Свои: редактор в GUI (фразы + workflow действий).
Активация: «включи игровой режим», комбобоксом в GUI.

### Настроение (aura/mood.py)
`{mood, energy, attention}`. Энергия тратится на команды (успех −1, ошибка
−3), восстанавливается со временем; фрустрация пользователя → concerned +
эмпатия; успех подряд → confident; бездействие `sleep_after_min` минут →
сон (аватар с z-z-z). Эмоция видна на аватаре и в нижней статус-панели.

## 11. Teach Mode и свои команды

### Teach Mode (aura/teach.py, pynput)
Кнопка «⏺ УЧИТЬ» → AURA записывает клики (координаты), печатаемый текст,
Enter/Esc/Tab/F-клавиши, Ctrl/Alt-комбо → «⏹ Стоп» → название → готовая
команда. **Умная очистка записи:**
- склейка дребезга кликов (интервал < 0.3 сек в ту же точку)
- слияние подряд идущей печати в один `type_text`
- нормализация пауз (< 0.5 сек — мусор, > — wait до 10 сек)
- отчёт: «6 сырых событий → 5 действий (убрано лишних: 2)»

### Свои команды (aura/skills/custom.py) — data/custom_commands.json
Редактор в GUI: название → фразы активации → цепочка действий (визуальный
конструктор: 20 типов кнопками, правка, переупорядочивание, подсказки) →
необязательный текст ответа. Для продвинутых — regex вместо фраз.
**Нечёткий поиск** (difflib, порог 0.75): «открой рабочую папкуу» найдёт
«открой рабочую папку». Навыки возвращают NO_MATCH → пробуются следующие.

## 13. Встроенные команды (aura/skills/builtins.py, ~35)

- **Ассистент**: «привет», «кто ты/что ты умеешь», «спи»/«проснись», «очисти историю»
- **Время/погода**: «который час», «какое число», «какая погода [в городе]» (wttr.in)
- **Интернет**: «найди …» (Google), «включи на ютубе …», «включи музыку»
  (URL настраивается), «что такое …» (Википедия)
- **Система**: «сделай громче/тише», «выключи звук», «громкость на 30»,
  «поставь на паузу», «следующий трек», «сверни все окна», «напечатай …»,
  «заблокируй компьютер», «выключи компьютер» (с подтверждением),
  «перезагрузи», яркость, «сделай скриншот» (файл + открыть папку)
- **Диагностика**: «статус системы» (CPU/RAM/диск/батарея/аптайм),
  **«почему компьютер тормозит?»** → CPU/RAM/диск + топ процессов + «Похоже,
  Chrome использует 2.8 ГБ. Закрыть?» (с подтверждением)
- **Файлы**: «найди презентацию …» (поиск по Desktop/Документы/Загрузки +
  папке проектов, фильтры по типам), «создай папку …», «заархивируй …»,
  «найди дубликаты» (md5-группы), «собери изображения из папки»
- **Память**: «запомни: …» (структурно: папка проектов, имя пользователя),
  «что ты помнишь», «открой мой последний проект»
- **Активность/зрение**: «отмени последнее действие» (undo), «что у меня на
  экране» (Vision), «нажми на кнопку …» (Vision→click)
- **Приложения**: «закрой браузер» (мягкое закрытие + undo), «открой …»
  (resolver), «ту ду лист / заметки» (открывает notes_app, по умолч.
  C:/todo/to-do), «запусти криту/юнити хаб/блендер» (quick_launch)
- **Развлечения**: анекдот, монетка, кубик

## 14. Интерфейс — Command Center (aura/gui.py)

**Композиция: лицо — центр экрана.**

## 16. Плагины (plugins/*.py)

```python
def register(api):          # вызывается при старте AURA
    def h_ping(t, m, ctx):
        return "Интернет на связи."
    api.add_skill("ping", [r"пинг"], h_ping)      # новая голосовая команда
    api.add_action("my_type", fn)                  # новый тип действия
    api.say("...")                                 # озвучка
    api.log("...")                                 # журнал
    api.config / api.memory                        # доступ к подсистемам
```

В комплекте `plugins/example_ping.py` — команда «пинг».

## 17. Безопасность

- Разрешения SAFE/NORMAL/GOD + 14 категорий (см. §9)
- Подтверждения «да/нет» голосом для опасного (питание, shell, python,
  удаление, покупка-категория, действия ИИ)
- `delete_path` не удаляет, а перемещает в `~/.aura_trash` (undo работает)
- ИИ не имеет прямого доступа к ОС — только предлагает действия через блок
- shell/python — отдельные категории, в SAFE запрещены
- API-ключи хранятся локально в data/settings.json (в .gitignore)

## 18. Запуск и проверка

```bash
pip install -r requirements.txt
python main.py          # или run.bat на Windows
python selftest.py      # самопроверка: 49 проверок
```

Linux: `sudo apt install python3-tk portaudio19-dev espeak-ng` перед pip.
macOS: `brew install portaudio python-tk`.
Без PySide6 запускается консольный режим (тот же мозг).

### selftest.py — 49 проверок, 3 секции
1. **Зависимости** (11 пакетов, обязательные vs опциональные)
2. **Ядро**: конфиг, память, разрешения (SAFE/NORMAL/GOD/override/strip_denied),
   режимы (загрузка, матчинг, сохранение), undo, настроение, мозг — 20+
   сценариев команд, нечёткий поиск, разбор блока ИИ, категории действий,
   машина состояний, resolver, очистка записи Teach, честный (ok, failed),
   VU-уровни, зрение, хоткеи
3. **UI-дым** (offscreen): окно строится, 5 вкладок, AURA MODE туда-обратно,
   эмоции аватара переключаются
